# Data Cleaning & Structural Validation

## Overview

This project focuses on transforming raw, unstructured data into a clean, consistent, and analysis-ready dataset as part of my Data Analytics internship.

## Data Cleaning Performed

- Auto-fitted rows and columns for better readability
- Used Find & Replace to clean and standardize text
- Standardized text using Lowercase & Uppercase
- Cleaned text using TRIM & PROPER
- Used Text to Columns to separate combined data
- Removed duplicate records
- Filled empty cells with appropriate values
- Handled calculation errors using IFERROR
- Applied consistent formatting to the dataset
- Removed gridlines for a cleaner presentation

## Tools Used

- Microsoft Excel
- Data Cleaning
- Data Formatting
- Structural Validation

## Project Outcome

The raw dataset was transformed into a structured, consistent, and analysis-ready format.
